# 公开 project 源码

本机维护五个独立项目，私有仓库保存开发历史。公开仓库为 xylograph-xg/project，五个源码目录共用一条发布历史。新建项目和 prompts 目录单独决定是否公开。

1. 在各源项目检查并提交本次变更。检查顶层启动脚本与 tool_registry 中的已提交副本。私有仓库按原分支备份。
2. 从本目录运行 `python3 export_public.py "$导出目录"`，目标为新的空目录。脚本逐项目读取已提交的文件，排除运行记录、会话授权、安装包及工作区外的链接，生成公开配置与独立的工具索引。
3. 比对上一版公开内容，检查新增文件与删除清单。对导出内容执行凭据扫描，并检查本机路径、邮箱、内网地址和私有会话标识。由当前发布者复核扫描结果。
4. 在另一目录检查工具箱双向链接与相关离线测试。将已审核树作为公开仓库 main 的下一次普通提交，使用 GitHub noreply 邮箱。推送前核对账号、远端和上游提交。保留既有公开历史。
5. 从 GitHub 核对公开可见性和目标提交，从未登录入口取回源码。记录五份来源提交和最终公开版本；运行数据和归档盘另行维护。

桌面清单位于 `~/Desktop/prompts/GitHub项目链接.txt`。公开目录变更后，按远端 main 已确认提交的完整 Git 树更新。首行写仓库首页，一级项目缩进一个 Tab，tools 排在最后，其下按实际公开的一级工具目录逐项列出并缩进两个 Tab。每行一个 URL 编码的 GitHub 链接。写回前核对版本、目录完整性、去重及增删项；读取失败保留原清单。
