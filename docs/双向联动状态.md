## 接口更新时的完成条件

1. 修改源项目实现和接口说明，核对实际使用方。
2. 同一任务更新 tools 工具卡、registry 的接口/限制/基线/验证记录及 CHANGELOG。新增、移除、改名还更新 README。
3. 更新受影响项目的适配/关系记录，以及 tools 端反向登记。验证范围不足的保留静态状态或待办，不冒充真实验收。
4. 运行全局更新和只读检查，在最终说明中列出两端修改和未完成项；有源码变化时先完成 all/RULES.md 的审查与使用方核对步骤。
