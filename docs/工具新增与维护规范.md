# 工具新增与维护规范

## 收录条件

适合收录的工具应完成一项明确能力，能够通过显式参数接收输入并返回可消费结果。代码可与原项目分离，必须明确仍依赖的数据、服务和系统环境。只在单个项目有意义的页面组件或业务流程不必强行抽象。

现有工具按已实现的接口登记；下面的要求约束新增和后续改进，不代表老工具已全部满足。

## 新工具交付内容

从 GitHub 克隆的公开仓库可使用 [生成 GitHub 工具接入命令的提示词](../templates/让ChatGPT生成GitHub工具接入命令的提示词.md)。无需向 ChatGPT 提供本机 tools 文件；提供明确 commit 后，由它先审核接口，再生成嵌入确定工具规格的仓库专用 `.command`。脚本运行时读取并验证本地 schema 后合并。生成物不是通用安装器，也不是验收证明；私有或未推送源码仍需提供，运行前仍需确认仓库、许可证、版本和脚本内容。

1. **稳定身份与权威位置**：选择唯一 `tool_id`；注明源码在哪维护、代码来源及允许的复用范围。默认使用原项目引用模式；迁入本目录时同步所有使用方，避免维护两个独立版本。
2. **独立接口**：至少提供 Python、CLI、HTTP 中一种。输入、输出、默认值、单位、范围、错误和副作用有完整说明。需要程序自动生成调用时提供 JSON Schema；普通 Python 工具不强制先建 HTTP 服务。
3. **明确依赖**：写明运行时版本、安装方法、平台限制、配置读取时机、外部文件与启动条件。不从调用进程当前目录猜测数据位置；通过参数或配置传入，记录默认值。
4. **最小调用与验证**：提供可复制的成功示例和失败/空结果示例，验证与原项目无关的工作目录中也能运行。根据影响测试关键算法、接口和副作用；轻量说明变更只需相关检查，不强制添加形式化测试。
5. **文档和登记**：按 `templates/工具说明模板.md` 创建 `tools/<tool_id>/README.md`；在 `registry.json` 新增条目，记录基线与实际验证；追加 `CHANGELOG.md`，登记使用方。
6. **第三方来源**：GitHub 仓库记录远程地址、当前 commit/tag 和许可证。默认引用克隆仓库的唯一源码位置；许可证不清楚、接口不稳定或只有内部业务流程时，不强行登记为可复用工具。

## 接口设计约定

| 项目 | 新增/改进时的要求 |
| --- | --- |
| 参数 | 名称稳定，拒绝非法类型与越界值；默认值需解释；禁止隐式修改调用方数据 |
| 结果 | 优先 JSON 可序列化结构；文本工具可以返回字符串，不能声称已经结构化验证 |
| 正常空结果 | 与异常分开，例如 `no_match`、`needs_root`，说明调用方如何继续 |
| 错误 | Python 用明确异常；CLI 提供退出码，成功 stdout 保持机器可读、诊断走 stderr；HTTP 定义状态码和错误体 |
| 超时 | 区分整体超时与阶段等待；失败时明确是否已执行、是否可能有部分结果 |
| 重试 | 说明幂等性；已发送消息、已写文件等操作不得不加判断地重复执行 |
| 并发 | 声明能否并发、共享资源及锁范围；不同实例不等于资源隔离 |
| 数据与状态 | 代码、业务数据、运行缓存分开；只读工具不得悄悄重建或写回数据 |
| 配置 | 通用实现不写死个人机器路径；示例配置可以展示本机值并说明如何替换 |
| 兼容性 | 不删除旧接口或改变字段含义而不说明迁移步骤；变更记录写清受影响调用方 |

需要正式版本时使用语义化版本：修复提升 PATCH、兼容能力提升 MINOR、破坏性变化提升 MAJOR。已有未版本化工具先记录实际状态，不凭空为其宣称上游版本。

## 与本目录联动的完成标准

- 权威源码和公开接口说明一致，最小示例可执行或注明未验证的外部前置条件。
- 清单的源码路径、接口入口、文件摘要、验证范围真实，工具卡从总 README 可找到。
- 使用方 `tool-dependencies.json` 记录所用能力、路径、验证基线，`consumers` 可反向定位项目。
- 维护方的 `exports` 与 registry 的 `owner_project` 双向对应，所有关联项目通过复制 all/ 并执行 all/setup.py 接入 `projects.json`。修改接口后必须运行 `python3 scripts/sync_tools.py update`，完成待审查项，再运行 `python3 scripts/check_links.py`；不要把静态核对当作真实接入验收。
- 通用修改在权威源码完成；业务定制在使用方适配层完成；兼容性和待迁移项目进入变更记录。
- 不收录登录态、`.pw-profile`、密钥、完整业务数据、缓存、虚拟环境和无关构建产物。
