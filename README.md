# 工具目录

每个一级目录对应一个工具。打开对应的 README 即可查看运行条件、调用命令和输入输出。说明中的相对路径以该说明所在目录为起点。

| 工具 | 用途 |
| --- | --- |
| [literature_explorer](literature_explorer/README.md) | 按主题发现文献，筛选候选并扩展引文。支持 Python 和 CLI。 |
| [codex_desktop_chat](codex_desktop_chat/README.md) | 通过 macOS 桌面 Chat 提问、上传附件和收取回答。支持 Python 和 JSON CLI。 |
| [codex_web_client](codex_web_client/README.md) | 通过持久队列向 Codex Web GPT 提交任务，按批号收取回答并核对结果。 |
| [oled-formulas](oled-formulas/README.md) | 安装 OLED 公式整理工具及配套组件，校验 wheel，查看公式处理命令。 |
| [tool_registry](tool_registry/README.md) | 登记使用方，检查源码指纹和双向链接，生成接口快照。 |
| [public_export](public_export/README.md) | 从五个项目的已提交源码导出公开发布目录。 |

前四个工具的权威源码位于各自工具目录。跨项目依赖可查[工具登记表](registry.json)和[使用项目索引](projects.json)。
